# 🌈 uni-prism 

> **One Source, Infinite Spectrums.** / 一束光芒，折射多端生态。

`uni-prism` 是我的 **uni-app 跨端应用个人总仓库**。如同物理学中的棱镜，这里是创意的单一源头（一套代码），经过跨端框架的折射，最终散落并盛开在微信、支付宝、抖音、H5、App 等多个不同的多维终端。

## 📐 核心理念 · Core Concept

* 🛠️ **单一源头 (The Ray)**：保持代码的优雅、凝练与高复用性。
* 🌈 **多端折射 (The Spectrum)**：完美适配多端生态，提供一致的用户体验。
* 🧪 **灵感实验 (The Laboratory)**：容纳每一个从 0 到 1 的轻量级创意。
