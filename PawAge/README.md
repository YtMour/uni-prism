## 🌟 项目愿景

**PawAge** 致力于打破传统“狗活 1 年等于人活 7 年”的粗暴过时观念。我们结合美国兽医协会（AVMA）及最新的犬类表观遗传学（UCSD）对数公式研究，打造了一款支持**按品种、按体型**精准换算生物年龄的工具。

这不仅是一个计算器，更是陪伴全球宠物主（Pet Parents）关注毛孩子衰老、行为转变与健康里程碑的情感与实用工具。

---

## 🚀 核心功能架构

### 1. 智能年龄转换器 (Precision Converter)
* **体型与品种加权：** 区分猫/狗，细化狗类体型（小型犬、中型犬、大型犬、巨型犬），使衰老曲线符合现代兽医学标准。
* **双向换算体验：** 既可从“宠物年龄 $\rightarrow$ 人类年龄”，亦可反向探索“如果我是人类的30岁，在猫咪世界里我是几岁？”增加互动趣味。
* **升级倒计时：** 精确到天和小时的“生物钟倒计时”，提示距离下一次“人类年龄跨度”还有多久，制造仪式感。

### 2. 深度生命周期分析 (Life Stage Analysis)
* **动态视觉时间轴：** 清晰划分 *幼年期 (Puppy/Kitten) $\rightarrow$ 青少年期 (Junior) $\rightarrow$ 成年期 (Adult) $\rightarrow$ 老年期 (Senior) $\rightarrow$ 高龄期 (Geriatric)*。
* **定制化养育指南：** 根据当前生命阶段，动态输出由海外兽医专家背书的营养调整、运动强度建议以及行为习惯转变提示。
* **健康体检预警：** 针对步入 Senior（老年期）的宠物，智能触发针对性的体检建议（如老龄犬的关节、血检防癌筛查提示）。

### 3. 多档案资产管理 (Multi-Pet Dashboard)
* 针对海外家庭多宠普遍的情况，提供流畅的横向卡片滑动体验，无上限管理多只猫狗的档案。

### 4. 社交裂变卡片 (Instaworthy Shareables)
* 一键生成高颜值的 Instagram / TikTok 故事卡片（例如：“*我的金毛 Max 今天生物年龄 3 岁了——它现在相当于一名 28 岁的大学毕业生！* 🎓”）。

## 🛠️ 技术选型与架构

* **前端框架：** uni-app (Vue 3 + Vite + Pinia)
* **UI 组件库：** 采用自定义轻量级组件，规避国内高饱和度电商风 UI，全量采用海外极简插画风。
* **数据持久化：** 本地优先（Privacy First）。利用 uni-app 的 `uni.setStorage` 或 SQLite，宠物数据 100% 留存在用户手机端，不强制注册登录，极大提升海外用户的信任度与下载转化率。
* **国际化 (i18n)：** 内置 `uni-i18n`，首发版本原生支持 英文 (US/UK)、日语、德语、法语、西班牙语。
