# PawAge 文档索引

本文档目录用于沉淀 PawAge 后续产品讨论、功能边界、商业化路线和实现优先级。根目录 `README.md` 继续承担项目愿景与技术概览，`Design.md` 继续承担视觉风格方向；本目录作为更细的产品与执行事实源。

## 文档列表

- `PRODUCT_STRATEGY.md`：产品定位、目标用户、核心价值、差异化和可行性判断。
- `MVP_SCOPE.md`：首发版本范围、页面结构、功能优先级和暂不做内容。
- `ROADMAP.md`：分阶段路线、优化方向、验证标准和后续迭代顺序。
- `RISK_AND_COMPLIANCE.md`：算法可信度、健康免责声明、应用商店审核和隐私边界。
- `IMPLEMENTATION_STATUS.md`：当前工程实现状态、已完成内容、进行中事项、验证结果和下一步建议。

## 当前推荐方向

PawAge 不应只做成一个单点年龄换算器。更稳妥的方向是：

1. 先用可信、漂亮、低摩擦的年龄换算建立下载理由。
2. 再用生命周期解释、提醒和分享卡片提升留存。
3. 最后用多宠档案、高级报告和自定义提醒承接订阅。

## 当前阶段判断

当前工程已进入 Phase 1 到 Phase 2 的交界：基础年龄换算、单宠档案、本地存储和主要页面框架已经可运行；下一步应优先补齐分享卡真实导出、设置页子流程、隐私免责声明和算法测试，而不是继续扩散新页面。

## 文档维护原则

- 所有功能状态必须区分 `已完成`、`进行中`、`待验证`、`暂缓`。
- 涉及健康建议时，不写成诊断或治疗结论。
- 涉及算法精度时，用“参考”“估算”“基于公开兽医指南”表述，避免绝对化。
- 海外市场首发优先英文体验，其它语言按 i18n 能力逐步补齐。
