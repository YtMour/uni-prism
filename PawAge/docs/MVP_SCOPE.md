# PawAge MVP 范围定义

## 一、MVP 目标

首发版本目标是做出一个可用、可信、好看的宠物年龄与生命周期工具。MVP 不追求功能大而全，而是尽快完成核心闭环：

> 创建宠物档案 -> 计算年龄 -> 理解生命阶段 -> 获得建议 -> 生成分享卡片。

## 二、首发功能

### 1. 宠物年龄换算

必须支持：

- 猫
- 狗
- 狗的体型分类：小型、中型、大型、巨型
- 出生日期输入
- 显示实际年龄
- 显示估算人类年龄
- 显示当前生命阶段

建议首发不做复杂品种库。品种库维护成本高，且不同来源数据不一致。首发可以先用体型作为主变量，后续再逐步加入常见品种预设。

### 2. 生命周期分析

必须支持生命阶段：

- Kitten / Puppy
- Junior
- Adult
- Senior
- Geriatric

每个阶段输出三类建议：

- Nutrition：饮食关注点
- Activity：运动和活动强度
- Wellness：体检或日常观察建议

建议内容要短，每类 1 到 2 条即可。移动端不适合塞长篇医学说明。

### 3. 单宠物档案

免费版支持 1 只宠物：

- 名字
- 类型：猫 / 狗
- 生日
- 狗体型
- 头像，可选

数据本地保存，不要求登录。

### 4. 分享卡片

首发至少支持一张竖版分享卡：

- 宠物名字
- 宠物照片或默认插画
- 真实年龄
- 人类年龄
- 当前生命阶段
- PawAge 品牌标识

分享卡优先适配 Instagram Story / TikTok 竖图比例。

### 5. 本地优先隐私

首发不做账号系统。宠物资料默认只保存在用户设备内。这样可以降低开发复杂度，也能强化海外用户信任。

## 三、首发页面结构

### 首页 / Dashboard

展示当前宠物卡片、年龄结果、生命阶段和主要建议。

### 新建 / 编辑宠物页

轻表单，不做复杂档案：

- 宠物名字
- 猫狗选择
- 狗体型
- 生日选择
- 头像

### 生命周期详情页

展示更完整的阶段解释、时间轴和建议。

### 分享页

生成卡片预览，支持保存或系统分享。

### 设置页

首发只放必要设置：

- 语言
- 隐私说明
- 免责声明
- Pro 入口，若暂未接入支付则作为占位介绍

## 四、暂不做内容

MVP 暂不做：

- 医疗诊断
- 疾病风险评分
- 药物建议
- AI 问诊
- 云同步
- 社区功能
- 完整品种数据库
- 复杂喂养计划
- 兽医预约

这些功能会显著增加审核、合规、数据和维护成本，不适合首发。

## 五、MVP 验收标准

功能验收：

- 能创建并保存 1 只宠物。
- 能根据生日和类型计算年龄。
- 狗能根据体型显示不同年龄估算。
- 能显示生命周期阶段。
- 能生成一张分享卡。
- 关闭 App 后宠物资料仍存在。

体验验收：

- 首次完成计算不超过 30 秒。
- 首页不出现密集表格。
- 所有健康建议都有免责声明入口。
- 英文文案自然，不像机器翻译。

技术验收：

- H5 构建通过。
- 核心年龄算法有独立数据或函数，便于测试。
- i18n key 不散落在组件中。
- 本地存储结构可迁移。
