# PawAge 后续路线与优化方向

## 一、阶段路线

### Phase 0：产品基础校准

目标：把现有愿景落成可开发规格。

工作项：

- 明确年龄算法的数据来源和边界。
- 确认猫、狗和狗体型的生命周期分段。
- 完成首发英文文案。
- 明确免责声明和隐私策略。
- 建立本目录下的产品事实源。

完成标准：

- MVP 范围清晰。
- 不再把健康建议写成诊断结论。
- 设计风格与功能页面能一一对应。

### Phase 1：核心工具闭环

目标：让用户能完成一次完整的年龄换算和档案保存。

当前状态：主体已完成，仍需补年龄算法测试和数据迁移策略。

工作项：

- 宠物档案模型。
- 年龄换算算法。
- 生命周期阶段映射。
- 首页结果卡。
- 本地存储。
- 设置页基础入口。

完成标准：

- 用户可以创建宠物并看到年龄结果。
- 数据刷新后不丢失。
- 猫和不同体型狗的结果有差异。

### Phase 2：情绪价值与视觉表达

目标：让 App 从计算器升级为宠物陪伴工具。

当前状态：页面骨架和主要视觉素材已接入，分享卡仍停留在预览占位，下一步应完成真实导出。

工作项：

- 生命周期时间轴。
- 阶段升级倒计时。
- 宠物头像和默认插画体系。
- 分享卡片。
- 更温暖的英文微文案。

完成标准：

- 分享卡可以保存为图片。
- 首页能清楚表达“宠物现在是什么阶段”。
- 视觉风格接近 `Design.md` 的 Soft Minimalism，而不是传统工具表单。

### Phase 3：留存与提醒

目标：提升重复打开理由。

工作项：

- 生日提醒。
- 阶段升级提醒。
- Senior 阶段体检提醒。
- 每周轻建议。
- 通知权限引导。

完成标准：

- 提醒内容可关闭。
- 不强迫开启通知。
- 老龄宠物提醒更有价值，但不制造恐慌。

### Phase 4：商业化

目标：验证 Pro 订阅价值。

工作项：

- 多宠档案。
- 高级分享模板。
- 高级生命周期报告。
- 自定义提醒。
- Pro 页面和订阅入口。

完成标准：

- 免费用户仍能完整完成基础换算。
- Pro 价值集中在多宠、长期管理和表达升级。
- 不把基础计算硬锁到付费墙后面。

## 二、重点优化方向

### 1. 算法可信度

年龄换算要做成可解释模块，不要散落在页面组件中。建议独立出：

- `species`
- `sizeClass`
- `actualAge`
- `humanAgeEstimate`
- `lifeStage`
- `nextStageDate`

未来若加入品种库，也能在这个结构上扩展。

### 2. 文案可信度

健康建议要避免绝对化。推荐用：

- may need
- consider
- commonly
- general wellness reference
- talk to your veterinarian

避免用：

- must
- diagnose
- prevent cancer
- guaranteed
- medically accurate

### 3. 首次使用流程

首屏不要先展示空 Dashboard。更好的流程是：

1. 选择猫 / 狗。
2. 输入生日。
3. 如果是狗，选择体型。
4. 立即看到结果。
5. 再提示是否保存为宠物档案。

这样可以降低首次体验阻力。

### 4. 多语言策略

首发可以优先英文，把其它语言作为可切换但逐步完善的能力。不要在英文文案还不自然时盲目铺开五种语言。

推荐顺序：

1. English
2. Japanese
3. German
4. French
5. Spanish

### 5. 视觉策略

`Design.md` 的方向成立，但要避免过度卡片化。宠物工具应有温暖感，但不能像营销落地页。

建议：

- 首页以结果和宠物为中心。
- 卡片用于宠物档案和报告块。
- 时间轴采用轻量渐变或脚印节点。
- 按钮和输入控件保持清晰，不牺牲可用性。

### 6. 数据与隐私

本地优先是正确方向。除非进入云同步阶段，否则不要引入账号系统。

需要提前设计：

- 本地数据版本号。
- 宠物档案迁移策略。
- 用户删除全部数据入口。
- 隐私政策中明确“不上传宠物资料”。

## 三、建议开发顺序

1. 建立年龄算法模块和测试样例。
2. 建立宠物档案数据结构。
3. 完成首页计算结果。
4. 完成新建 / 编辑宠物页。
5. 完成生命周期建议数据。
6. 完成分享卡片。
7. 补设置、免责声明、隐私说明。
8. 做 i18n 和构建验证。

## 四、关键指标

首发后建议关注：

- 首次计算完成率。
- 保存宠物档案比例。
- 分享卡生成比例。
- 次日留存。
- 多宠用户比例。
- Senior 宠物用户比例。

其中最关键的是保存档案和分享卡生成。如果用户不保存、不分享，说明产品还只是一次性工具。
