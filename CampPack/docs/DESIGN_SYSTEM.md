# CampPack 设计系统

## 1. 视觉方向

CampPack 使用 Gallerist Minimalism。界面应像克制、通透的户外装备目录，而不是卡通露营贴纸集合。

关键词：

- 大面积留白。
- 低饱和自然色。
- 高可读文字。
- 清晰层级。
- 轻量触感反馈。

## 2. 色彩

| 用途 | 颜色 | 说明 |
| --- | --- | --- |
| App 背景 | `#FBF9F5` | 温暖纸张色 |
| 次级背景 | `#F0F1EE` | 大地浅灰 |
| 主文本 | `#1E1E1E` | 黑曜石 |
| 品牌强调 | `#2A3A2C` | 苔藓深绿 |
| 警示 | `#B65D3A` | 低饱和陶土色 |
| 成功 | `#4E6B4B` | 深林绿色 |
| 边框 | `#DDD8CE` | 纸张阴影边界 |

避免使用高饱和霓虹色、厚重蓝紫渐变、大面积橙棕单色主题。

底部导航、固定操作区和其他覆盖在滚动内容上方的栏位必须使用不透明背景，当前 H5 使用 `#FBF9F5`。不要在这些区域使用半透明白或毛玻璃效果，否则列表内容会透出并和导航图标/文字重叠。

## 3. 字体

- 标题 / 分类: Playfair Display、Lora 或系统 Serif fallback。
- 正文 / 条目: Inter、Montserrat 或系统 Sans-serif fallback。
- 数字 / 重量: 使用等宽数字特性，保证统计值不跳动。

在 App 端必须优先保证系统字体可用，不应为了审美阻塞首屏渲染。

## 4. 核心组件

### 4.1 顶部概览

展示当前清单名称、模式切换、完成度、总重量。移动端不做复杂图表，优先用进度条和紧凑数字。

### 4.2 模式切换

Pack / Setup / Leave 使用分段控件。当前模式必须清晰可见，切换时不弹出干扰性说明。

### 4.3 装备条目

条目卡片包含：

- 勾选控件。
- 装备名称。
- 数量。
- 重量。
- 分类标签。
- 备注图标或关键标记。

整行可点击，勾选区域不小于 44px。长文本必须换行或截断，不能挤压数量和重量。

### 4.4 分类区块

分类标题使用较小的 Serif 字体，不做夸张 hero 字号。分类可以折叠，但 MVP 可先保持全部展开。

### 4.5 模板卡片

模板卡片用于展示模板名称、适用场景、装备数量和估算重量。不嵌套卡片。

### 4.6 图标资产

生成类 PNG 图标必须在页面层保留安全边距。圆形图标容器、模板图标容器、设置图标容器和底部导航图标容器默认不裁切图标内容；如需裁切，应先确认图标本身有足够透明留白。

当前实现使用 `static/icons/ui/` 的轻量 PNG 作为 H5 运行资源，原始大图保留在 `static/icons/` 和 `assets/design/icons/`。后续平台发布时仍需导出 App 图标和启动图的正式多尺寸资源。

## 5. 交互原则

- 勾选后触发短促震动，H5 / 小程序无能力时静默降级。
- Leave 模式进入前给出一次明确确认，避免用户误以为覆盖 Pack 状态。
- 删除清单、清空状态、重置 Leave 必须二次确认。
- 搜索和筛选优先使用底部操作区或顶部紧凑筛选，不打断清点流。

## 6. 可访问性

- 文本和背景对比度必须满足移动端阅读。
- 触控目标不小于 44px。
- 所有状态不能只依赖颜色，需要图标、文本或形态辅助。
- 户外强光场景下，关键数字和勾选状态必须一眼可辨。

## 7. 页面设计稿

后续 App 实现优先参考 `assets/design/screens/` 下的页面级设计稿：

- `01-lists-home.png`: 清单首页。
- `02-template-library.png`: 模板库。
- `03-checklist-pack.png`: Pack 清单详情。
- `04-checklist-leave.png`: Leave 清单详情。
- `05-gear-editor.png`: 装备编辑。
- `06-settings.png`: 设置页。

这些图片用于确定页面结构、组件组合、状态表达和视觉密度。生成图中的字体大小、图标细节和局部文案不需要逐像素复刻，实现时以可读性、触控面积和跨端稳定性为准。
