# CampPack QA 检查清单

## 1. 功能验收

### 清单管理

- [ ] 可以创建空白清单。
- [ ] 可以从模板创建清单。
- [ ] 可以重命名清单。
- [ ] 可以复制清单。
- [ ] 删除清单前有二次确认。
- [ ] 清单删除后不会影响其他清单。

### 装备条目

- [ ] 可以新增装备。
- [ ] 可以编辑名称、数量、重量、备注、关键标记。
- [ ] 可以删除装备。
- [ ] 分类内排序稳定。
- [ ] 长名称不会挤压重量和状态控件。

### 三阶段清点

- [ ] Pack 模式勾选后刷新仍保留。
- [ ] Setup 模式勾选不影响 Pack 状态。
- [ ] Leave 模式初始化只基于 Pack 已勾选装备。
- [ ] Leave 状态重置不会覆盖 Pack / Setup。
- [ ] 三个模式的完成度分别正确。

### 重量与单位

- [ ] 公制显示 g / kg。
- [ ] 英制显示 oz / lb。
- [ ] 总重量计算正确。
- [ ] 已勾选重量计算正确。
- [ ] 未填写重量的条目不会导致 NaN。

### 搜索与筛选

- [ ] 按名称搜索可用。
- [ ] 按分类筛选可用。
- [ ] 只看未完成可用。
- [ ] 只看关键装备可用。
- [ ] 清空搜索后恢复完整列表。

## 2. 离线验证

- [ ] 首次打开不依赖网络请求。
- [ ] 断网后可以创建和编辑清单。
- [ ] 断网后可以导入内置模板。
- [ ] 断网后 App 重启数据仍保留。
- [ ] 无网络时不出现阻塞性错误弹窗。

## 3. 数据安全

- [ ] 数据 schema 版本存在。
- [ ] 读取旧版本数据会走 migration。
- [ ] 写入失败有用户提示。
- [ ] 删除和重置类操作有确认。
- [ ] 导入异常数据不会导致白屏。

## 4. 性能检查

- [ ] 100 条装备勾选无明显卡顿。
- [ ] 300 条装备滚动可接受。
- [ ] 搜索不会造成长时间阻塞。
- [ ] 统计值变化不造成整页跳动。

## 5. 视觉与交互

- [ ] 触控目标不小于 44px。
- [ ] 当前模式清晰可见。
- [ ] 勾选状态不只依赖颜色。
- [ ] 户外强光下核心文字和状态有足够对比。
- [ ] 弹窗、按钮、长文本不重叠。

## 6. 发布前

- [ ] 隐私政策存在。
- [ ] 商店截图覆盖核心流程。
- [ ] App 图标和启动图存在。
- [ ] Android 真机 smoke 完成。
- [ ] iOS 真机 smoke 完成。
- [ ] 构建命令和版本号记录在发布文档中。
