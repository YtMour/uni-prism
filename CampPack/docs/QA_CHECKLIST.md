# CampPack QA 检查清单

## 1. 功能验收

### 清单管理

- [x] 可以创建空白清单。
- [x] 可以从模板创建清单。
- [x] 可以重命名清单。
- [x] 可以复制清单。
- [x] 删除清单前有二次确认。
- [ ] 清单删除后不会影响其他清单。

### 装备条目

- [x] 可以新增装备。
- [x] 可以编辑名称、重量、备注。
- [x] 可以编辑数量和关键标记。
- [x] 可以删除装备。
- [x] 可以调整装备分类。
- [ ] 分类内排序稳定。
- [ ] 长名称不会挤压重量和状态控件。

### 三阶段清点

- [x] Pack 模式勾选后刷新仍保留。
- [x] Setup 模式勾选不影响 Pack 状态。
- [ ] Leave 模式初始化只基于 Pack 已勾选装备。
- [x] Leave 状态重置不会覆盖 Pack / Setup。
- [x] 三个模式的完成度分别正确。

### 重量与单位

- [x] 公制显示 kg。
- [x] 英制显示 lb。
- [x] 总重量计算正确。
- [ ] 已勾选重量计算正确。
- [x] 未填写重量的条目不会导致 NaN。

### 搜索与筛选

- [ ] 按名称搜索可用。
- [ ] 按分类筛选可用。
- [ ] 只看未完成可用。
- [ ] 只看关键装备可用。
- [ ] 清空搜索后恢复完整列表。

- [x] H5 刷新后数据仍保留。

- [x] 删除和重置类操作有确认。

## 5. 视觉与交互

- [ ] 触控目标不小于 44px。
- [ ] 当前模式清晰可见。
- [ ] 勾选状态不只依赖颜色。
- [ ] 户外强光下核心文字和状态有足够对比。
- [ ] 弹窗、按钮、长文本不重叠。
- [x] H5 底部导航栏使用不透明背景，不允许滚动内容透出重叠。
- [x] 应用图标、分类图标、设置图标和底部导航图标在容器内保留安全边距，不被圆形或卡片容器裁切。
- [x] Templates 移动端卡片不会因 Import 按钮挤压正文，标题、元信息和标签保持可读布局。
- [x] Templates 筛选项 All / Solo / Family / Ultralight 在移动端保持单行显示，且文字不被裁切。
- [x] 组件化后 `IconMark` 图标在 H5 中不回退为 320 x 240 默认尺寸。
- [x] 组件化后 Lists 卡片、Templates 卡片、Settings 列表和底部导航都由子组件持有核心布局样式，避免父页面样式穿透失效。
- [x] 页面切换后滚动位置会重置，避免从列表或模板页进入详情页时顶部标题被裁切。
- [x] Template 筛选按钮有选中状态并实际过滤卡片，Import 会把模板加入清单并跳回 Lists。
- [x] Checklist Detail 中模式切换、装备勾选、Leave 重置和完成按钮都有可见状态变化。
- [x] Gear Editor 中数量加减、单位切换、关键装备开关、删除和保存按钮都有可见反馈或导航结果。
- [x] `npm run audit:visual` 可检查图标安全边距、底部导航不透明、滚动区底部预留、按钮对齐和关键交互绑定。
- [x] 已用右侧浏览器在 430 x 844 视口检查 Lists / Templates / Settings / Checklist Detail / Gear Editor / Leave 模式的图标、卡片、顶部栏、底部导航和主要点击链路。
- [x] `npm run smoke:h5` 覆盖模板导入、刷新持久化、三阶段状态独立、Leave reset、空白清单创建/删除、清单重命名/复制、装备新增/字段编辑/分类调整、隐私页、数据重置确认、JSON 导出/导入、语言/单位持久化和 430px 视口横向溢出。
