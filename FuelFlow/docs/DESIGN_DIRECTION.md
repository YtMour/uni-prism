# FuelFlow 设计方向

## 设计原则

### 1. 先记录，再欣赏

用户打开 app 的第一目标通常是完成记录或查看当前车辆状态。界面可以优雅，但不能为了视觉展示牺牲输入效率。

### 2. 数字必须成为主角

油耗、油价、总金额、里程和月度支出是核心信息。视觉层级应让关键数字在 1 秒内被看见，辅助说明保持克制。

### 3. 克制但不冷

FuelFlow 避免传统汽车工具的黑红、碳纤维、齿轮、仪表盘拟物风格。整体应接近现代画廊、精品旅行工具和高质量财务 app 的结合。

### 4. 移动场景优先

加油站、停车场、车内等场景光线和注意力都不稳定。按钮、输入区和关键数字要足够大，对比度要足够高。

## 视觉语言

### 色彩

推荐基础色：

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| Canvas | `#FBF9F5` | 温暖纸感背景 |
| Surface | `#FFFFFF` | 主要内容面 |
| Ink | `#172126` | 主文字 |
| Muted | `#6F7672` | 次级说明 |
| Fuel Blue | `#1A3644` | 主操作和品牌色 |
| Route Green | `#2B4C3F` | 正向状态和商务标签 |
| Amber | `#B8792F` | 油价、提醒和成本强调 |
| Line | `#E7E1D8` | 分隔线 |

注意：
- 不要让界面被单一蓝色或绿色统治。
- 背景应保持轻盈，深色只用于关键文字、主按钮和图表强调。
- 成本类信息可使用 Amber，但不能变成警告式焦虑表达。

### 字体

推荐策略：
- 数字：Inter、SF Pro、Roboto 或系统无衬线体。
- 少量品牌标题或车辆昵称：可使用 Lora / Playfair Display 风格，但只作为点缀。
- 中文界面如后续支持，优先系统字体，避免衬线中英混排带来的不稳定。

字体层级：

| 层级 | 用途 |
| --- | --- |
| Display Number | 当前油耗、月度成本、累计里程 |
| Title | 页面标题、车辆名 |
| Body | 记录摘要、字段标签 |
| Caption | 单位、更新时间、辅助说明 |

## 信息架构

建议底部导航 4 个主入口：

| Tab | 作用 | MVP |
| --- | --- | --- |
| Dashboard | 当前车辆概览、关键指标、趋势入口 | 是 |
| Logs | 加油和用车成本记录列表 | 是 |
| Garage | 多车辆管理和车辆切换 | 是 |
| Reports | 导出、税务摘要、年度报告 | 后置 |

主操作：
- 底部中间或右下角常驻 Add 按钮。
- Add 内部提供 Fuel、Trip、Expense 三类入口。
- MVP 阶段可先突出 Fuel，Trip 和 Expense 作为次级入口。

## 关键页面方向

### Dashboard

核心内容：
- 当前车辆卡片。
- 本月油费。
- 平均油耗。
- 最近一次加油。
- 简洁趋势图。
- 快速新增入口。

布局建议：
- 顶部显示车辆名和切换入口。
- 首屏以 2 到 3 个关键数字为主。
- 趋势图占据中部，不放进厚重装饰卡片。
- 最近记录只展示 3 条，完整历史进入 Logs。

### Add Fuel

核心字段：
- Vehicle
- Date
- Odometer
- Fuel volume
- Total cost
- Price per unit
- Full tank
- Business / Personal
- Note

交互建议：
- 金额、油量、单价允许任意两项推导第三项。
- 默认带入上次车辆、单位和货币。
- Business / Personal 用明显的分段控件。
- Full tank 是影响油耗计算可信度的重要开关。

### Logs

核心内容：
- 按月份分组。
- 单条记录展示日期、金额、油量、里程、油耗结果。
- 支持 Fuel、Trip、Expense 类型筛选。
- 支持 Business / Personal 快速筛选。

### Garage

核心内容：
- 车辆名称、品牌型号、单位偏好、当前里程。
- 单车统计摘要。
- 新增车辆。

设计重点：
- 车辆切换要轻，不应进入复杂设置页。
- 家庭用户和自由职业司机都可能有多车。

### Reports

核心内容：
- 时间范围。
- Business / Personal 汇总。
- Fuel / Maintenance / Insurance / Tolls 分类支出。
- CSV 导出。
- PDF 报告后置。

MVP 可以先做导出设计，不一定第一阶段实现 PDF。

## 组件风格

- 卡片圆角控制在 8px 左右，避免过度圆润。
- 图表用细线、少网格、明确数字标注。
- 输入按钮要大，但不要做游戏化。
- 图标使用线性风格，避免复杂汽车拟物图标。
- 状态色要服务于理解，不要为了装饰引入过多颜色。

## 不建议方向

- 深色赛车仪表盘。
- 大面积霓虹渐变。
- 碳纤维、齿轮、速度表拟物。
- 复杂 3D 车辆模型。
- 首屏营销大标题。
- 把所有功能塞进首页卡片墙。
