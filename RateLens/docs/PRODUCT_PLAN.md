# RateLens 产品计划

## 产品定位

RateLens 是面向跨境消费和旅行场景的轻量汇率工具。第一优先级不是金融交易或资产管理，而是让用户在海外购物、餐饮、出行和网购时快速知道真实本币成本。

## 目标用户

- 出境旅行者：关注价格、税费、小费和 AA 分摊。
- 海外网购用户：需要快速判断商品本币价格。
- 留学生和长期旅居者：需要固定关注几组常用币种。
- 跨境内容创作者：需要在不同币种之间快速换算预算和报价。

## 核心场景

1. 在餐厅输入账单金额，快速算出含税、小费和人均金额。
2. 在商店看到外币价格，输入金额后立刻看到本币成本。
3. 打开 App 查看 4-6 个常用币种的同步换算结果。
4. 没有网络时继续使用最近一次缓存汇率完成估算。

## MVP 功能边界

必须包含：

- 多币种联动换算。
- 最近一次汇率缓存与离线回退。
- 税率、小费、AA 分摊。
- 本币与关注币种设置。
- 基础语言切换与本地化数字格式。

暂不包含：

- OCR 和 AR 覆盖。
- 桌面小组件。
- 账号系统。
- 历史曲线和投资盯盘。
- 真实支付、订阅和云端同步。

## 商业化假设

首版应先验证留存和使用频次，再接入真实商业化。

- 免费层：核心换算、离线缓存、基础旅行计算。
- 高级层：更多币种卡片、税率模板、历史趋势、小组件、拍照识别。
- 付费前置条件：核心体验稳定、有明确隐私政策、有平台权限声明。

## 合规与隐私原则

- 用户输入金额默认只在本地处理。
- 不采集通讯录、精确定位等无关权限。
- 若未来接入 OCR，需要明确说明相机权限用途。
- 若未来使用云端识别，需要区分本地计算数据和上传识别数据。

## 体验原则

- 金额输入必须快，避免金融软件式复杂表单。
- 离线状态要清晰，但不制造焦虑。
- 汇率更新时间必须可见。
- 长文本、多语言和大数字必须优先考虑自适应布局。
