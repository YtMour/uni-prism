# UI Style Guide

## Style Name

Gallerist Minimalism.

The app should feel like a quiet contemporary gallery tool, not a dark editing
suite and not a sticker-heavy social app.

## Palette

| Token | Value | Usage |
| --- | --- | --- |
| Paper | `#F9F7F2` | Main canvas background. |
| Gallery Gray | `#EFEFEF` | Secondary page background. |
| Midnight Ink | `#1A2A3A` | Primary text and main actions. |
| Espresso | `#3C2F2F` | Alternative accent and warm labels. |
| Mist Sage | `#E5EAE6` | Quiet control surfaces. |
| Soft Red | `#D96B6B` | Destructive or warning actions. |

Avoid a one-note beige interface. Use the paper palette as a surface system and
let photo content bring color.

## Typography

- Brand and template names: elegant serif, such as Playfair Display or Lora.
- Functional labels and numeric metadata: Inter, Montserrat, or a similar
  readable sans-serif.
- Metadata rows should be compact and readable at small sizes.
- Do not use viewport-width font scaling.

## Layout

- The first screen should be the editor experience once the app exists.
- Keep the photo and frame as the visual center.
- Controls should be compact, predictable, and grouped by task.
- Use sliders for numeric adjustments.
- Use icon buttons for direct tools when a familiar icon exists.
- Avoid nested cards.
- Use stable aspect-ratio containers for preview thumbnails and photo surfaces.

## Motion

- Motion should be quiet and functional.
- Use progress feedback during export.
- Avoid decorative motion that competes with the photo.

## Generated Design Asset Direction

Generated assets should follow these constraints:

- Warm paper and gallery surfaces.
- Realistic or high-fidelity app mockup composition.
- Minimal controls.
- No loud neon, glassmorphism, dark studio UI, or stock-photo atmosphere.
- No fake brand marks from real camera companies.
- No unreadable dense UI text unless the image is explicitly a mood reference.

## First Asset Set

The first generated image set should include:

1. Product visual direction board.
2. Mobile editor interface mockup.
3. EXIF gallery-frame export example.

These assets are references for alignment and should not be treated as final UI
screens.
