# StrateName 产品规格

## 产品一句话

StrateName 是一个移动优先的企业命名生成器，帮助创始人、咨询顾问和企业服务团队快速生成、筛选、解释和展示稳重可信的公司、集团、咨询机构、投资平台和实体业务名称。

## 目标用户

| 用户 | 需求 | 成功标准 |
| --- | --- | --- |
| 中小企业创始人 | 为新公司、分公司或业务线找到稳重名称 | 10 分钟内得到 3 到 5 个可进入人工尽调的候选 |
| 咨询顾问/品牌顾问 | 为客户提案准备多个公司命名方向 | 能批量导出候选、理由和风格说明 |
| 地产/工程/制造团队 | 为项目公司、控股平台或工程品牌命名 | 名称有规模感、信任感和行业根基 |
| 投资/资本/控股团队 | 为基金、SPV、控股集团或 advisory 命名 | 名称专业、国际化、不过度活泼 |
| 创业团队 | 为 B2B、服务业或跨境业务找公司名 | 名称便于读写、可搭配 Inc./LLC/Ltd. 等后缀展示 |

## 核心使用场景

### 场景 1：快速生成稳重企业名

用户选择：

- 行业：Finance & Capital
- 风格：Global Venture & Capital
- 组织形式：Holdings / Capital / Partners
- 稳重程度：Boardroom

系统输出 8 个候选，并展示评分、结构拆解、命名理由和风险提示。

### 场景 2：按行业收敛命名方向

用户选择 `Real Estate & Construction`，系统优先使用 `Summit`、`Stone`、`Harbor`、`Civic` 等稳固意象词根，并搭配 `Development`、`Properties`、`Group`、`Holdings` 等后缀。

### 场景 3：对比多个候选

用户把候选加入 Shortlist，对比：

- 名称长度
- 词根来源
- 行业匹配
- 专业度
- 可信度
- 法律/商标风险提示
- 用户备注

### 场景 4：生成董事会提案卡

用户选择 `Crestway Partners`，系统生成 Boardroom Proposal：

- 企业信笺顶端预览
- 写字楼前台墙预览
- 商务名片预览
- 提案封面预览
- 一句定位文案和行业标签

### 场景 5：导出给人工尽调

用户复制候选列表和命名理由，交给律师、商标代理、注册代理或内部决策人进一步确认。

## MVP 范围

### 必须实现

| 功能 | 说明 |
| --- | --- |
| 本地名称生成 | 不依赖服务端，用结构化词库和规则生成 |
| 三大商业风格 | Global Venture & Capital、Heritage Industrial、Neo-Enterprise Blend |
| 行业过滤 | Finance & Capital、Consulting & Service、Real Estate & Construction、Logistics & Trade |
| 组织形式切换 | Group、Holdings、Capital、Partners、Industries、Trading、Trust、Ltd.、Inc.、LLC、Corp. |
| 稳重程度控制 | Conservative、Boardroom、Modern、Premium 四档 |
| 长度控制 | Short、Standard、Formal Compound |
| 候选评分 | 专业度、可信度、行业匹配、可读性、差异性和风险提示 |
| 详情拆解 | 展示词根、后缀、组织形式、行业理由和发音提示 |
| 收藏/取消收藏 | 本地保存候选名称和用户备注 |
| Shortlist 对比 | 收藏候选的对比列表 |
| 复制导出 | 复制单个名称、候选列表和提案摘要 |
| Boardroom Proposal | App 内预览，不承诺第一版真实 PNG 保存 |
| 本地持久化 | 保存最近生成、收藏、备注和基础偏好 |
| 隐私政策 | 独立页面说明本地存储范围、未收集内容、用户控制和不远程传输；支持 16 种主流语言 |
| 免责声明 | 独立页面说明名称仅为创意建议、不做公司注册/商标/域名可用性检查、非法律/财务/商业建议、发布前由用户自行尽调；支持 16 种主流语言 |
| H5 构建验证 | 至少完成浏览器 H5 构建、静态 smoke 和真浏览器 smoke |

### 应该实现

| 功能 | 说明 |
| --- | --- |
| seed 复现 | 同一 seed 可复现同一批候选，便于复盘和报告 |
| 禁用词过滤 | 过滤敏感词、真实知名品牌、高混淆商标片段、负面含义和难读组合 |
| 重复率采样 | 用脚本检查批量生成重复率 |
| 质量采样报告 | 输出长度、评分分布、重复率、禁用原因和行业覆盖 |
| 响应式适配 | 覆盖 360px 到桌面宽度 |
| 法律文案多语言 | 隐私政策和免责声明支持 en、zh-Hans、zh-Hant、es、fr、de、ja、ko、pt-BR、it、ru、ar、hi、id、tr、vi |
| 导出摘要 | 复制包含候选名、行业、风格、评分和免责声明的纯文本 |

### 暂缓

| 功能 | 暂缓原因 |
| --- | --- |
| 实时公司注册查询 | 各国/州/地区数据源不同，错误提示和合规成本高 |
| 商标检索 | 法律风险高，第一版不应暗示可注册或无侵权风险 |
| 域名可用性查询 | 需要外部 API、速率限制和错误处理 |
| AI 生成 | 会增加成本、延迟、隐私和不可控质量 |
| 云同步/账号 | MVP 不需要 |
| 团队协作 | 先验证单人命名流程 |
| 真实 PNG 保存 | 需要字体授权、截图、权限和裁切回归 |
| 地区注册规则智能判断 | 各地区差异大，第一版只做展示后缀，不做法律判断 |

## 信息架构

| 页面/区域 | 内容 |
| --- | --- |
| Home / Generator | 标题、行业、风格、组织形式、长度、稳重程度、生成按钮、候选列表 |
| Candidate Card | 名称、标签、评分、收藏、复制、重新组合 |
| Detail Sheet | 名称结构、词根来源、行业理由、评分拆解、风险提示、相似变体 |
| Shortlist | 收藏列表、对比表、备注、复制全部、清空 |
| Boardroom Proposal | 信笺、前台墙、名片、提案封面预览 |
| Settings | 默认行业、默认风格、结果数量、seed、过滤强度、法律语言、隐私政策入口、免责声明入口、清空本地数据 |
| Privacy Policy | 独立法律文档页，显示所选语言的隐私说明 |
| Disclaimer | 独立法律文档页，显示所选语言的免责声明 |

## 成功指标

MVP 阶段优先使用本地质量指标：

- 单次生成 8 个候选，至少 5 个通过基础可读性和风险过滤。
- 1000 次批量生成重复实例率低于 8%。
- 默认名称主体长度控制在 5 到 18 个字符，不含 `Ltd.`、`Inc.`、`LLC` 等法律后缀。
- 候选平均评分高于 78 分。
- 每个行业至少有 40 个核心词根、16 个后缀和 12 个可复用结构。
- 360px 宽度下核心流程无横向滚动。
- 复制、收藏、刷新恢复和清空数据可稳定工作。

## 非目标

- 不提供法律意义上的公司名称可注册性判断。
- 不承诺商标、域名、社媒账号或公司登记可用。
- 不把法律后缀展示解释为成立、注册或合规建议。
- 不把生成结果、收藏或设置上传到远程服务。
- 不生成或推荐明显包含真实知名公司、真实品牌或高混淆商标的名称。
- 不在 MVP 中做复杂 logo 设计器、VI 手册或完整品牌战略服务。
