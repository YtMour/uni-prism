# VibeName 产品规格

## 产品一句话

VibeName 是一个移动优先的创业项目命名生成器，帮助独立开发者和 SaaS 创业者快速生成、筛选、收藏和预览科技产品名称。

## 目标用户

| 用户 | 需求 | 成功标准 |
| --- | --- | --- |
| Indie hacker | 为新工具、模板、插件或 AI wrapper 找名字 | 10 分钟内得到 3 到 5 个可继续评估的候选 |
| SaaS 创业者 | 为早期产品、功能模块或新品牌线命名 | 候选名称能体现业务领域和产品气质 |
| 开发者工具作者 | 为 CLI、SDK、平台或 dashboard 找短名称 | 名称短、清晰、便于传播和读写 |
| 设计师/产品经理 | 做概念提案时快速生成品牌 placeholder | 能复制列表并生成概念卡片 |

## 核心使用场景

### 场景 1：快速启动命名

用户输入或选择：

- 行业：AI / ML
- 风格：Micro-SaaS Blend
- 长度：Standard Blend
- 调性：Clean

系统输出 8 个候选，并显示评分、理由和可收藏按钮。

### 场景 2：锁定喜欢的词根

用户喜欢 `Flow`，将其锁定。后续生成围绕 `Flow` 组合不同后缀、行业词和抽象音节。

### 场景 3：对比候选名称

用户把 6 个名称加入 Founder Whiteboard，对比：

- 名称长度
- 音节数量
- 行业匹配
- 可读性
- 品牌感
- 用户备注

### 场景 4：品牌概念预览

用户选择 `Flowbase`，系统生成一张极简概念卡片：

- 名称
- 一句假定 tagline
- 行业标签
- 主色预览
- 首屏式布局

## MVP 范围

### 必须实现

| 功能 | 说明 |
| --- | --- |
| 本地名称生成 | 不依赖服务端，用结构化词库和规则生成 |
| 风格选择 | Micro-SaaS Blend、Neomorphic Abstract、Action-Driven |
| 行业过滤 | 至少支持 AI、DevTools、Fintech、Creator Economy |
| 长度过滤 | Ultra Short、Standard Blend、Descriptive Compound |
| 候选评分 | 显示可读性、品牌感、领域匹配和长度评分 |
| 收藏/取消收藏 | 本地保存候选名称 |
| Founder Whiteboard | 收藏候选的对比列表 |
| 复制导出 | 复制单个名称和候选列表 |
| 概念卡片预览 | App 内预览，不承诺第一版 PNG 保存 |
| 本地持久化 | 保存最近生成、收藏和基础偏好 |
| 隐私政策 | 分段说明本地存储范围、未收集内容、使用目的、不出售/不远程传输、保留期限、用户控制、安全限制和后续变更条件 |
| 免责声明 | 分段说明名称仅为创意建议、不做可用性检查、商标/品牌风险、非专业建议、按现状提供、发布前由用户自行尽调 |
| 主流语言国际化 | Settings 提供 18 个主流应用语种选择，核心界面、关键设置、隐私政策和免责声明随 locale 更新 |
| H5 构建验证 | 至少完成浏览器 H5 构建与 smoke |

### 应该实现

| 功能 | 说明 |
| --- | --- |
| seed 复现 | 同一 seed 可复现同一批候选 |
| 禁用词过滤 | 过滤敏感词、明显负面词和难读组合 |
| 重复率采样 | 用脚本检查批量生成重复率 |
| 质量采样报告 | 输出长度、评分分布和重复率 |
| 响应式适配 | 覆盖 360px 到桌面宽度 |
| 语言覆盖与审校 | 已接入 18 个主流应用语种，Arabic 支持 RTL；核心交互、法律页和可见选项说明已本地化，后续继续做专业文案审校 |

### 暂缓

| 功能 | 暂缓原因 |
| --- | --- |
| 实时域名查询 | 需要外部 API、速率限制和错误处理 |
| 商标检索 | 法律风险高，第一版不应暗示可注册 |
| AI 生成 | 会增加成本、延迟和不可控质量 |
| 云同步/账号 | MVP 不需要 |
| 团队协作 | 先验证单人命名流程 |
| 真实 PNG 保存 | 需要字体、截图、权限和裁切回归 |

## 信息架构

| 页面/区域 | 内容 |
| --- | --- |
| Home / Generator | 标题、风格、行业、长度、生成按钮、候选列表 |
| Candidate Card | 名称、标签、评分、收藏、复制、重新组合 |
| Detail Sheet | 名称结构、生成理由、评分拆解、相似变体 |
| Founder Whiteboard | 收藏列表、对比表、备注、复制全部 |
| Concept Preview | 极简品牌卡片预览 |
| Settings | 默认风格、默认行业、结果数量、语言、生成/过滤偏好、分段隐私政策、分段免责声明、清空本地数据 |

## 成功指标

MVP 阶段优先使用本地质量指标：

- 单次生成 8 个候选，至少 5 个通过基础可读性过滤。
- 1000 次批量生成重复率低于 8%。
- 候选名称长度默认控制在 4 到 14 个字符。
- 360px 宽度下核心流程无横向滚动。
- 复制、收藏、刷新恢复和清空数据可稳定工作。

## 非目标

- 不提供法律意义上的商标可用性判断。
- 不承诺域名一定可注册。
- 不把生成结果、收藏或设置上传到远程服务。
- 不生成包含真实公司、真实品牌或高混淆商标的名称。
- 不在 MVP 中做复杂 logo 设计器。
