## Phase 1：工程脚手架与最小生成器

状态：Not Started

目标：

- 创建 `VibeName-Uniapp` 工程。
- 建立本地命名生成核心。
- 完成浏览器 H5 可运行页面。

交付：

- uni-app + Vue 3 工程。
- `src/core/generator`。
- `src/data` 首批词库。
- 首页生成流程。
- 候选卡片。
- 基础测试。
- H5 dev/build 命令。

验收：

- 能生成 8 个候选名称。
- 支持至少 3 种风格和 4 个行业。
- 候选不为空、不重复、不明显难读。
- `npm test` 和 `npm run build:h5` 可运行。

## Phase 2：评分、过滤与白板

状态：Not Started

目标：

- 让生成结果可解释、可对比、可收藏。

交付：

- 可读性评分。
- 品牌感评分。
- 行业匹配评分。
- 禁用词过滤。
- 收藏/取消收藏。
- Founder Whiteboard。
- 本地持久化。
- 复制单个名称和复制全部。

验收：

- 刷新后收藏仍保留。
- 评分维度展示清楚。
- 复制失败有降级反馈。
- 360px 宽度下白板可用。

## Phase 3：概念卡片与质量验证

状态：Not Started

目标：

- 建立可发布候选所需的质量采样和视觉预览。

交付：

- Concept Preview。
- 自动 tagline 生成。
- seed 复现。
- `sample:quality`。
- `smoke:h5`。
- `assess:release`。
- 文档状态同步。

验收：

- 1000 次采样重复率低于 8%。
- 质量报告可输出到 `reports/`。
- H5 smoke 覆盖生成、收藏、复制、白板、预览。
- 无横向滚动和明显文字遮挡。

## Phase 4：H5 MVP 候选加固

状态：Not Started
