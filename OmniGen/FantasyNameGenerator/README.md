# Module: Fantasy Name Generator (幻想命名生成器) 🌌✨

> 赋予虚无以姓名。作为 OmniGen 矩阵的艺术序列核心，本模块专为奇幻小说作者、D&D 跑团 DM（地下城主）以及 RPG 游戏玩家提供不枯燥、具备史诗质感的角色姓名与神话词汇生成。

---

## 🎨 视觉定位与微调

*   **交互点缀色：** 采用降低饱和度的**暮色深紫 (#1C1A27)**，烘托奇幻文学的隐秘感与星尘质感。
*   **卡片质感：** 文字生成面板采用微弱的**磨砂玻璃（Glassmorphism）**叠加柔和弥散阴影，使结果如同漂浮在占卜画布中央。
*   **核心展示字体：** 锁定为具备古典史诗感的西方高级衬线体 *Cinzel* 或 *Playfair Display*。

---

## 🚀 核心功能规划 (Feature Architecture)

### 1. 三大奇幻种族序列生成 (The Trinity Realms)
*   **精灵序列 (Elf Names)：** 
    *   *风格：* 优雅、轻盈、富有自然与星光的流动感。
    *   *音节矩阵：* `前缀(柔和前鼻音: Ae-, Ere-, Cael-)` + `中缀(流音: -lia-, -thil-)` + `后缀(优雅自然音: -gorn, -wind)`。
    *   *示例：* `Caerithon`、`Aeliana`。
*   **巨龙序列 (Dragon Names)：** 
    *   *风格：* 沉重、威严、带有古老火焰与碎石的压迫感。
    *   *音节矩阵：* `前缀(爆破音: Ig-, Thor-, Vol-)` + `中缀(颤音: -rax, -vath)` + `后缀(强尾音: -os, -or)`。
    *   *示例：* `Ignisvath`、`Thoraxor`。
*   **魔法/古老咒语序列 (Magic & Spells)：** 
    *   *风格：* 神秘、深奥，适用于法术技能命名或上古法器。
    *   *音节矩阵：* 基于拉丁语系、凯尔特语系的古典词根变体组合。
    *   *示例：* `Aetheris Crux`、`Vortex Lumina`。

### 2. 神话维度过滤器 (Mythos Filters)
*   **性别筛选：** 支持指定 `雄性 (Masculine)` / `雌性 (Feminine)` / `中性 (Gender-Neutral)`。
*   **阵营倾向：** 支持勾选 `光明 (Holy)` / `暗影 (Shadow)` / `混沌 (Primal)`。生成器将根据阵营自动调整底层字母矩阵（例如：暗影阵营将自动提高 `-mor`, `-vath` 等低沉音节的出现概率）。

### 3. 创作者灵感口袋 (Inspiration Pocket)
*   **一键收藏与克隆：** 遇到中意的名字可双击快速收入本地暂存夹。
*   **画廊海报导出：** 支持将选中的名字一键转化为一张带有极简画廊装裱线条、排版优雅的“灵感视觉卡片”图片，供作者直接保存或分享至创作者社区。
