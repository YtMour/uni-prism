# MythosGen Product Plan

## 产品定义

**MythosGen: Fantasy Name Creator** 是一款面向创作者的奇幻命名应用。它服务于 D&D 跑团玩家、地下城主、奇幻小说作者、RPG 游戏玩家和独立游戏开发者，帮助他们快速获得具有史诗感、可复用、可收藏和可分享的幻想姓名与神话词汇。

## 核心价值

- 快速生成可直接用于角色、地点、法术和神器的名字。
- 通过种族、性别、阵营、语感强度等过滤器控制结果风格。
- 把好名字保存为创作素材，而不是一次性随机文本。
- 用画廊式视觉卡片提升分享、归档和创作者社区传播价值。

## 目标用户

| 用户 | 场景 | 核心需求 |
| --- | --- | --- |
| D&D 玩家 | 创建角色、NPC、家族与地名 | 快速、有阵营感、可保存 |
| DM / GM | 即兴补充世界观细节 | 大量生成、分类明确、复制方便 |
| 奇幻作者 | 小说人物、组织、法术命名 | 语感稳定、风格一致、可二次编辑 |
| RPG 玩家 | 游戏角色、宠物、装备命名 | 移动端快用、结果好看 |
| 独立游戏开发者 | 原型阶段命名素材 | 批量生成、导出、可复用 |

## MVP 范围

MVP 只做最能验证产品价值的闭环。

- 三类生成器：Elf Names、Dragon Names、Magic & Spells。
- 三组过滤器：Gender、Alignment、Tone。
- 结果操作：Generate、Copy、Favorite、Regenerate Variant。
- 收藏口袋：本地保存、删除、按类型筛选。
- 海报导出：单个名字导出为图片卡片。
- 设置项：触感反馈、动画强度、默认生成类型。

## 非 MVP 范围

- 账号系统、云同步和社区发布。
- 大模型在线生成。
- 复杂世界观数据库。
- 多语言本地化。
- 订阅、支付和广告投放。

## 商业化方向

第一阶段不把商业化作为阻断项，但产品结构需要预留扩展。

- Pro 解锁更多领域：Dwarf、Orc、Demon、Celestial、Ancient Kingdoms。
- 高级过滤器：文化语感、音节长度、黑暗程度、神圣程度。
- 导出样式包：古卷、星图、徽章、档案卡。
- 批量导出：供作者或游戏开发者整理素材。
- 去广告或支持开发者的一次性购买。

## 产品原则

- 生成结果必须是主角，控制项保持安静。
- 随机不是噪声，规则和权重要让结果具备可解释风格。
- 收藏、复制和导出必须比设置参数更顺手。
- 移动端优先，桌面端只作为验证和推广入口。
