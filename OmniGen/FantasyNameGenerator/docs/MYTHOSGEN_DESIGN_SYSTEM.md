# MythosGen Design System

## 设计关键词

MythosGen 的视觉语言是暗紫点缀下的极简画廊风。界面应该像一个安静的灵感仪式空间，而不是参数面板。

- 主画布：羊皮纸白 `#FBF9F5`
- 文字主色：墨黑 `#17151D`
- 点缀色：暮色深紫 `#1C1A27`
- 柔和边框：雾灰 `#E7E1D8`
- 成功/收藏：古金 `#B88A44`
- 危险/删除：深酒红 `#7E2E35`

## 字体

- 生成结果：`Cinzel`、`Playfair Display` 或系统 serif fallback。
- 控制项：系统 sans-serif，保持克制、清楚、低存在感。
- 数字和标签不使用夸张字重。

## 首页结构

移动端第一屏应直接进入生成体验。

1. 顶部三段式品牌栏：左侧品牌符号与 MythosGen，中间当前 Realm 胶囊，右侧声明/设置入口图标。
2. 顶部品牌栏下方使用细分隔线与小星标，弱化但明确分层。
3. 中央生成画布不做厚重卡片，不使用明显矩形底板；结果名字、纹章、分隔符和 metadata 是主视觉。
4. 底部控制区先放 Realm segmented control，再放工具栏式 Filter / Copy / Favorite / Export。
5. 背景保持干净，可用极轻羊皮纸纹理，但不能出现明显的整块纹理矩形、强烈渐变或装饰球。

## 核心交互

- 轻触中央画布生成新结果。
- 长按结果复制。
- 双击结果收藏。
- 左右滑动切换 Realm。
- 摇晃手机触发生成，设置中可关闭。
- 导出按钮生成图片卡片，不打断当前生成流。

## 组件规范

| 组件 | 规范 |
| --- | --- |
| 顶部栏 | 品牌、Realm 胶囊和 Pocket/声明入口三段式布局；Pocket 使用列表/书签语义，存在收藏时只显示内嵌小金点，不使用外露数字角标，避免裁切和压住图标 |
| 结果舞台 | 无外框主舞台，避免卡片化；名字应为最大视觉元素 |
| Realm 切换 | 三项常驻分段控件，外层轨道统一承载边框；内部三项等宽、等间距、等圆角，选中项为深紫底，不能用内部边线造成某一项圆角异常 |
| 操作栏 | 图标在上、文字在下，使用浅色胶囊工具条承载四个等宽动作；不使用竖线切分成表格，也不做重边框卡片按钮 |
| 过滤器 | 底部抽屉，分组使用 segmented row；Gender 为三段连续控件，Alignment/Tone 可带符号 |
| 收藏列表 | 独立 Pocket 面板，宽度与 App 容器对齐；顶部含返回、标题和搜索占位，Realm tabs 可筛选；列表行包含选择圆点、名字、metadata、复制和删除图标操作；底部保留选中计数和导出选中入口 |
| 设置页 | 包含声明、本地数据说明、默认 Realm、触感反馈和动画强度 |
| 导出预览 | 独立全高预览面板，宽度与 App 容器对齐；内部单个卡片填满按钮上方可用空间，保留边距和装裱线，不触发页面外层滚动 |
| Toast | 用于复制、收藏、导出完成，不遮挡名字 |

## 视觉检查基线

首页实现以 `design/imagen/home-generation.png` 为主参考，过滤器以 `design/imagen/filters-sheet-v2.png` 为主参考。实现不需要像素级复刻，但需要满足以下基线：

- 首屏不能像参数表单或后台面板，控件必须安静地让位给生成结果。
- 结果区不能被一张大卡片框住；如果使用纹理，纹理边界不能可见。
- 底部工具栏不能出现一排重边框矩形按钮。
- 底部工具栏不能出现竖线分割的表格感；应是一条轻量胶囊工具条，内部动作等宽但视觉连续。
- 首屏纵向节奏应稳定：顶部栏和底部控件固定，结果舞台占据中间弹性空间；底部控件应贴近第一屏底部，避免无说明的大块尾部空白。
- 结果舞台允许大面积留白，但需要用纹章、名字、metadata、提示文案和细分隔线形成完整视觉闭环，不能让名字组孤立悬浮。
- 过滤器抽屉需要有顶部 grabber、居中标题、右侧关闭图标、分组分隔线、Reset / Apply 双操作。
- 过滤器保持底部抽屉，不应被 Export 的全高面板样式污染成整页面板。
- Export 页面不应出现外层浏览器滚动条，底部按钮不能贴出视口；卡片和按钮应在一屏内完整可见。
- Pocket 顶部入口若有收藏状态，只显示小金点提示，不在小按钮里显示容易裁切的数字。
- 若透明素材自带留白导致图标过小，应优先使用稳定符号或后续重新裁切素材，不能让布局依赖不可控透明边界。

## 海报导出

导出卡片应保持可分享和可归档。

- 默认视觉比例：卡片内容保持 4:5 海报构图感；H5 预览面板可为适配一屏显示而使用弹性高度。
- 内容：名字、Realm、Alignment、生成日期、小型 MythosGen 标识。
- 风格：极简装裱线、低饱和背景、衬线体名字。
- 不加入大面积二维码、广告或解释文案。

## 可访问性

- 深紫文字和浅色背景需要保持足够对比度。
- 触控目标不小于 44px。
- 关键操作必须有非手势入口。
- 动画强度可关闭或降低。
